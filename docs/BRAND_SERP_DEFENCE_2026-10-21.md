# Brand SERP defence — 2026-10-21

Read-only diagnosis of the Wellness Nest house-brand position slide. Every figure is summed from the Search Console CSV named below. This file does not edit the theme, the homepage, products, collections, pages, checkout, landing listicles, or any blog article.

## Sources and method

Primary file: `/Users/kevinkreative/genseo-wt/inputs/2026-10-21-gsc-raw.csv`.

Reader: `wn_clusters.read_gsc_csv`. Store-name phrases are built from `wn_clusters.BRAND_WORDS` (wellness nest, wellnessnest, and the misspellings wellnes nest, welness nest, wellnest). A lone "wellness" or "nest" is not the store. House lines: fusiforce, shilasource, florafresh, ageaura, menomate, shockwave, and gold resin only when the query also says shilajit. Bare turkesterone stays with the other queries.

Position is impression-weighted across date and device. The CSV `ctr` column is not used. A query average can sit in the 20s while one of our URLs on that query is still near the top, because the average mixes every URL that received impressions.

Windows are the minimum and maximum `date` values present on the rows, not a date typed in by hand.
