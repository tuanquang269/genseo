# GenSeo SEO Optimizer (The Triage Manager)

This skill acts as the Technical Audit triage. It no longer audits single pages arbitrarily. Instead, it reads the bulk `CRAWL_REPORT.csv` from the Sitemap Crawler, diagnoses the severity of the broken 404 links and structure issues, and passes repair orders to the Refresh Agent.

## When to Use
- The `sitemap_crawler.py` has finished running and produced a CSV and an `OPTIMIZER_ACTION.md` ticket.
- You need to clean up broken internal links across the entire Your Brand site.

## The Process

1. **Information Ingestion:**
   - Use the `view_file` tool to read the `CRAWL_REPORT.csv` generated by the crawler.

2. **Analysis & Triage:**
   - Filter out pages that are completely healthy.
   - For pages with "Missing H1s" or "Missing Alts", categorize them as "Structural Warnings".
   - For pages with raw `404 Broken Links`, categorize them as "Critical Emergencies".

3. **Dispatch Repair Orders:**
   - For every Critical Emergency (404 link), you must issue a targeted prompt asking the user to trigger the `genseo-content-refresh` agent to fix it.
   - Example prompt creation:
     "Hand this to `/genseo-content-refresh`: The live URL [PAGE_URL] contains a broken 404 link: [BROKEN_A_TAG]. Please pull the live content, locate this link, either remove it or replace it with a valid API-checked Shopify handle, and run the publisher."

4. **Output Dashboard:**
   - Present a Markdown dashboard counting the Total Pages Scanned, the Number of Broken Links, and the Actionable Prompts ready for the user to copy-paste.
